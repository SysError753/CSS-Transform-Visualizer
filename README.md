# 🎨 CSS Transform Visualizer

A small interactive project built with **HTML and CSS** to visually demonstrate different CSS `transform` properties.

This project was created as a practice project while learning **CSS Transforms, Hover Effects, and Transitions**.

## ✨ Features

The project demonstrates the following CSS transform functions:

- `scaleX()`
- `scaleY()`
- `scale()`
- `rotateX()`
- `rotateY()`
- `rotateZ()`
- `rotate()`
- `translateX()`
- `translateY()`
- `translate()`
- `skewX()`
- `skewY()`

Hover over each box to see the corresponding transformation in action.

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Transforms
- CSS Transitions
- Flexbox

## 🚀 How to Run

1. Clone the repository:

```bash
https://github.com/SysError753/CSS-Transform-Visualizer.git
```

2. Open the project folder.

3. Open `CSS Transform.html` in your browser.

4. Hover over the different boxes to see the CSS transformations.
